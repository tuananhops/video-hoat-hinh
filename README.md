# video-hoat-hinh

Gói "bộ não" của bot **video hoạt hình**: trợ lý AI làm video marketing hoạt hình/explainer có thuyết minh tiếng Việt (trailer tín dụng BĐS 16:9, quảng cáo tuyển đại lý 9:16).

## Cách dùng
Clone repo rồi bảo bot đọc AGENTS.md:
```bash
git clone https://github.com/tuananhops/video-hoat-hinh.git
```
> "Đọc AGENTS.md và thư mục skills/ rồi làm theo."

## Cấu trúc
```
AGENTS.md / CLAUDE.md   chỉ dẫn cho bot (giống hệt nhau)
rules.md                quy tắc, cài đặt, lỗi đã mắc, ghi chú công cụ
skills/                 các skill (đọc trước tiên)
scripts/                công cụ dòng lệnh (ffmpeg + Python)
examples/               cấu hình mẫu đã duyệt (chỉ text)
```
